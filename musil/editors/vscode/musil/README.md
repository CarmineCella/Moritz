# Musil for VS Code

Syntax highlighting for `.mu` files, and live coding: send code to a running Musil.

## Keys (in a `.mu` file)

- **Cmd-Enter** (Ctrl-Enter): send the block around the cursor, or the selection
- **Cmd-Shift-Enter**: send the whole file
- **Cmd-Alt-Enter**: send the current line

The block flashes when sent; the reply (a value, `ok`, or the error) shows in the status
bar. A block is the lines between blank lines around the cursor.

## What receives the code

`musil --serve 7770 -i` (or `(serve 7770)` in any script) opens the evaluation port 7770 and
evaluates what arrives as if it were typed. The port asks for a token: musil writes a random one when the
port opens, to `~/.musil/port-7770.token` (or to a private folder in the temporary directory), readable by
you alone, and the extension sends it first. So only your own programs can run code there. Host and port
are settings (`musil.host`, `musil.port`).

## Installing

During development: copy or link this folder to `~/.vscode/extensions/musil-<version>`
(`ln -s "$PWD" ~/.vscode/extensions/musil-<version>`) and reload the window.

For distribution: `npx @vscode/vsce package` in this folder makes `musil-<version>.vsix`;
install it with *Extensions: Install from VSIX*, or `code --install-extension musil-<version>.vsix`.

From a shell: `musil --send 7770 block.mu`, or `echo '(+ 1 2)' | musil --send 7770` (both read the
token). With plain `nc`, the token goes first and macOS's `nc` needs a Ctrl-D byte at the end:
`printf '%s\n(+ 1 2)\n\004' "$(cat ~/.musil/port-7770.token)" | nc localhost 7770`.

The grammar (`syntaxes/musil.tmLanguage.json`) lists every builtin and library function;
it is generated by `tools/gendoc.py` from the same doc comments as `help` and the manual.
