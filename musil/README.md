# Musil, the scripting language of Moritz

Musil is a small Lisp whose numbers are vectors, with libraries for offline
signal processing and analysis, statistics and learning, and music. In
Moritz it is the scripting language: you write it in the code editor or at
the Console, and scripts reach patches through buffers and messages (see
the main [README](../README.md#programming-inside-moritz-with-musil)).

Musil was a project of its own (github.com/CarmineCella/musil, now
archived). It lives on here and stays independent: nothing in this folder
uses Moritz.

- `src/` is Musil 0.9.1 exactly, the core (`core.h`) and the libraries that
  Moritz uses: `std`, `system`, `scientific`, `signals` and `music`, each a
  C++ half (`.h`) and a half written in Musil (`.mu`), with their data.
  `tools/check-musil.sh` checks every file against the tag. Musil's live
  library (its audio engine) and its plot and controls windows are left out,
  since Moritz plays and draws; `live.mu` and `plot.mu` are here because
  `music.mu` loads them.
- `help.txt` is the documentation of Musil as Moritz uses it, generated by
  `tools/musil-help.py`.
- `tests/` holds Musil's tests, run with `tools/test-musil.sh` (through
  `moritz --run`) and `make embed-test` (built from `src/` alone).

What Moritz adds to Musil lives on Moritz's side, in `src/musil_host.h` and
`src/session.cpp`, never here.
