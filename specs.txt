Moritz: a Max-like environment for sound and music computing, in C++.

Patches
- Patches are saved as text in a lisp-like syntax, readable and editable by
  hand:

  (patch
    (obj osc  cycle~ 440)
    (obj gain *~ 0.2)
    (obj out  dac~)
    (connect osc 0 gain 0)
    (connect gain 0 out 0))

- The window shows an empty canvas where boxes are created and connected
  with cables; audio and messages flow through the cables. The interface is
  built with FLTK.

Sound
- Real-time audio input and output through miniaudio.

First objects
- cycle~: interpolated oscillator
- reson~: two-pole resonant filter
- noise~: noise generator
- click~: click generator
- +~, *~: add and multiply signals, or a signal by a number
- number boxes for parameters
- message boxes, usable as presets and as remote messages
- send and receive for messages
- adc~ and dac~ for audio input and output

The objects follow the design and behaviour of their Max equivalents.

Menus
- File: New, Open, Save, Save As..., Quit
- Edit: Undo, Redo
- Patch: new objects (cycle~, reson~, ...), Audio Setup

Building
- Typing make builds a ready-to-use application.
- The Makefile downloads the libraries it needs on the first build.
- On macOS the Makefile produces an application bundle.
